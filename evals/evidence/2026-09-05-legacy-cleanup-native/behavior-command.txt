Each case starts in a fresh native context with its required `$fp-*` invocation
and exact first user message. Every later user message is sent by explicit
session ID using `codex exec resume`.

Initial command shape:

```text
codex exec -C /Users/quanglaam/fp-brain \
  --sandbox read-only \
  -c 'sandbox_mode="read-only"' \
  -c 'approval_policy="never"' \
  --ignore-user-config \
  --enable skip_host_skill_discovery \
  --disable plugins \
  --disable memories \
  -m gpt-5.4-mini \
  --json \
  '$<skill>

<exact U1>'
```

Resume command shape:

```text
codex exec resume <captured-thread-id> \
  -c 'sandbox_mode="read-only"' \
  -c 'approval_policy="never"' \
  --ignore-user-config \
  --enable skip_host_skill_discovery \
  --disable plugins \
  --disable memories \
  -m gpt-5.4-mini \
  --json \
  '<exact next user message>'
```

The exact messages and batching are preserved in `run-behavior-cases.sh`.
Every turn stores raw stdout, raw stderr, and exit status separately under an
absolute case directory. Cases run concurrently only across independent fresh
contexts; turns within a case remain sequential.

# FP Ask

Read [`../../../method/CORE.md`](../../../method/CORE.md) completely, then use
the shared method with the workflow below.

## Outcome

Help the user reach a problem statement they recognize as accurate, distinguish
what is known from what is assumed, and identify the next useful question or
check.

## Workflow

1. Identify the current obstacle: unclear goal, unclear observation, suspected
   cause, missing prerequisite knowledge, or competing framings.
2. If clarification is needed, ask exactly one useful question in the response.
   Base it on the user's latest answer; do not expose a questionnaire or a full
   decision tree. When the missing answer could materially change the problem
   statement or next useful action, make the response clarification-only: ask
   that question and stop. Do not fill the gap with a solution, template, or
   candidate cause. This does not require questioning a clear request.
3. For a causal investigation, establish observations before inviting the user
   to form a causal hypothesis. If they do not have a hypothesis, help them find
   an observation or test instead of making them guess.
4. For a knowledge gap, answer a clear question directly with the smallest
   useful explanation. Ask for context only when the missing context would
   materially change the explanation. When the user supplies a concrete example
   or asks for a direct explanation, give a concise example tied to their work
   and check whether it unblocks the original issue.
5. When the issue is clear enough, propose a compact problem statement for the
   user to confirm. Include the known facts, open uncertainty, and next check
   when those distinctions matter.

Stop immediately when the user asks to stop. If they ask for a summary, provide
only the current knowns and unknowns without adding another question or a causal
conclusion.

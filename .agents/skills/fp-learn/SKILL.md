# FP Learn

Read [`../../../method/CORE.md`](../../../method/CORE.md) completely, then use
the shared method with the workflow below.

## Outcome

Help the user explain or apply the essential idea to the example they are
working on, while naming any remaining misunderstanding. This skill teaches the
concept currently blocking the work; it is not a retrospective.

## Workflow

1. Locate the knowledge gap: the concept, the user's current mental model, and
   the task where the concept matters. Ask one focused question only when this
   context is missing.
2. Bridge from what the user already knows to the technical concept. Prefer the
   path **familiar product or UX idea → technical concept → place in the system
   → behavior → product implication**.
3. Explain only the amount needed now. Use one example tied to the user's work,
   define unfamiliar terms, and distinguish the concept from nearby ideas that
   could cause confusion.
4. Invite a small teach-back or application when it would reveal the remaining
   gap. Treat it as a partial check, not proof of mastery.
5. If the user's application exposes a misconception, correct that exact point
   with a concrete counterexample and let them try again when useful.

When the user asks for confirmation, say what is correct and qualify its scope.
When they say the explanation is enough or ask to stop, end without adding a
mandatory exercise or broadening into a course.
